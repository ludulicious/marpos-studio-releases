# Marpos Studio

Public installers, signed updates, and developer documentation for Marpos Studio: a desktop content workspace for Astro and Nuxt Content websites.

- [Download Marpos Studio](https://github.com/ludulicious/marpos-studio-releases/releases)
- [Prepare your website for Studio](docs/README.md)
- [Astro integration guide](docs/astro.md)
- [Nuxt Content integration guide](docs/nuxt-content.md)
- [AI prompts for adapting an existing website](docs/ai-prompts.md)

You do not need access to Marpos Studio's source code to integrate your website. Keep content, schemas, rendering components, and optional Studio configuration in your own website repository.

Start with your framework's guide, then use the [authoring configuration reference](docs/authoring.md) to improve the editing experience and the [handover checklist](docs/verification.md) to verify it.
